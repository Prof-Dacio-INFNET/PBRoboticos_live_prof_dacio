## Como funciona uma aula ao vivo

Três blocos, como na presencial: **teoria-ponte** (o conceito que liga o que as DRs ensinaram ao que o seu projeto precisa), **mão na massa** (todo mundo roda o mesmo exemplo, com um *ponto de controle* a cada 15–20 minutos — você cola a saída do comando no chat) e **mentoria** (compartilhamento de tela de quem travou, na ordem da fila do chat). Pausa de 10 minutos no meio. Terminou um bloco? `git add . && git commit && git push` — a gravação não salva o seu código.
